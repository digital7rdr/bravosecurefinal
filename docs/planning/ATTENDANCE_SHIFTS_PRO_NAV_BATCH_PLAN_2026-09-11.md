## 5. Edge cases (initial — the edge-case agent extends)

1. A worker assigned to two overlapping shifts (two orgs) — the on-shift predicate is per shift id; a ping for shift A answered while the open session is for shift B → server: allowed only if now is inside A's window and assigned; document.
2. Worker with location permission denied → responder answers `refuse` with reason `no_permission`; manager sees "Couldn't share location".
3. Ping while the worker's app is killed → notification card; if never opened → `expired` at 10 min; no location.
4. Manager pings themselves (assigned to their own shift) → allowed, same lane.
5. Series across a DST change — `occurrences` windows are absolute ISO; the client generates each day at the same local wall time (reuse the existing weekly generator's approach).
6. Exclusions leave zero dates → Create disabled with copy.
7. R2 with the Departmental gate showing (≥ 2 workspaces, none chosen) — no attendance read fires (the gate suppresses the surface); the agent shell has a context by resolver.
8. Back at the Pro dashboard with a pending modal/sheet open → the sheet closes first (existing N-rules).
9. The Messenger tile while a call is live → unchanged (call overlay rules).
10. Avatar URL expired/403 → initials fallback, viewer shows the fallback with a retry.
